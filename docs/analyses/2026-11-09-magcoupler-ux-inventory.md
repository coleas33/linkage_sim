# Magcoupler web tool: inventory of user-facing surfaces (2026-11-09)

Input to the magcoupler UX overhaul design. Produced by a read-only code-mapping pass (Sonnet, under Fable as controller) over `magcoupling-rs/` and `linkage-sim-rs/web/` at commit 1048962 plus the uncommitted model-role edits. Nothing in the repo was edited or staged by that pass.

On-screen strings were measured with a throwaway headless harness in the session scratchpad (`scratchpad/dump/`). It runs the real `MagcouplingPanel` on egui 0.32.3 at 1280x800 and prints every painted text shape. Tooltips are not in those dumps, because they only build on hover.

Paths are relative to `magcoupling-rs/src/` unless they start with `linkage-sim-rs`. Notes live under `engine/explain/`.

## Headline findings

- First paint at 1280x800 draws 727 words in 121 text shapes. The whole page, dashboard scrolled to its end, is about 1,230 words.
- The four biggest contributors at first paint: the torque card (163 words), the Size controls with their hints and lines (145), the open Hot-minimum Problem/Why/Fix block (108), the callout list and notes under the drawing (88).
- The Start-here tour is reachable only after opening the Equation panel and clicking **Start here** inside it. A new user never sees it.
- The drawing's parts have no hover or click. Only dimension lines and their list rows are interactive.
- The Assumptions view cannot be reached while the Size and torque tab is selected.
- Five rows read "Why: no note yet": Cup outer diameter, Rotating mass, Clearance (inside its block), Space claim, Magnets fit.
- No font is bundled; the tool uses egui's default fonts. The theme is forced dark; no light theme exists.
- Nothing persists between visits: no local storage, and the URL is not updated while editing. Share links and design files carry the inputs plus the sizing state.
- The hub page card blurb still says "clamps" while the clamp section is paused. A plot readout shows a stray trailing unit ("never: steady state stays below the limit s").

## 0. Web shell

- **HTML host:** `linkage-sim-rs/web/tools/magcoupler/index.html` (committed). The glue `magcoupling-web.js` and the wasm are generated by `linkage-sim-rs/scripts/build_magcoupling_web.sh` and gitignored.
- **Static text in the shell:**
  - `<title>Magnetic Coupling Calculator</title>` (index.html:6).
  - Favicon is `/favicon.svg`.
  - Body background is `#1e2026`, which equals `panel_fill` (30,32,38). A test in `app/theme.rs` enforces the match.
  - `<canvas id="magcoupling_canvas">` is 100% x 100% with `overflow:hidden`.
  - Nothing else: no loading text, no `<noscript>`, no spinner, no fonts or CSS beyond that.
- **Entry:** `bin/magcoupling_web.rs:21-70` (`start()`).
  - It routes logging to the browser console (`eframe::WebLogger`).
  - It reads `?m=<payload>` (`SHARE_PARAM = "m"`, `gui/session.rs:79`) and opens that design. A refused link keeps the default design and logs a warning.
  - It sets the share base to `origin + pathname` of the page.
  - It uses `eframe::WebOptions::default()`.
  - The title is never set from Rust on the web (`app.rs:15` `TITLE` is only the native window title).
- **URL behaviour:** the URL is never updated while you edit (no `pushState` or `replaceState`).
- **Redirects:** `linkage-sim-rs/web/vercel.json` redirects `/magcoupling/*`, `linkage.colesorkness.com/?tool=magcoupling` and `?m=` links to `/tools/magcoupler/`.
- **Hub page:** `web/tools/index.html:63-67` has a card "Magnetic Coupling Calculator". Its blurb reads "Coaxial magnetic slip couplings: torque, end effects, temperature, clamps, and design checks." This still mentions clamps while the clamp section is paused.

## 1. Layout skeleton

`MagcouplingPanel::ui` (`gui/panel.rs:691`) lays out four regions in this order:

1. Top header: `TopBottomPanel::top("magcoupling_header")`, panel.rs:704.
2. Left inputs: `SidePanel::left("magcoupling_inputs")`, resizable, default width `INPUTS_WIDTH = 320.0` (panel.rs:190, 707).
3. Right dashboard: `SidePanel::right("magcoupling_dashboard")`, resizable, default width `DASHBOARD_WIDTH = 300.0` (panel.rs:193, 722), vertical `ScrollArea` id `magcoupling_dashboard_scroll`.
4. Centre: `CentralPanel` (panel.rs:739), `centre_ui` at panel.rs:890.

There is no bottom bar or status strip. The only bottom panel is the Equation panel, docked at the foot of the centre region when open. There are no modal windows (`egui::Window` appears only when linkage-sim-rs hosts the panel). The only popups are hover tooltips, combo-box dropdowns and the native or browser file dialogs.

## 3. Teaching content

### 3a. Notes registry (`engine/explain/notes.rs`)

There are 21 notes in `NOTES` (:159). All are `Review::Reviewed`. 20 are shown, because the paused clamp note is hidden (`shown`, notes.rs:~1344). Each note is drawn as:

## 5. The drawing

`geometry_ui` (`geometry_view.rs:158`), data from `geometry.rs`. It is drawn on both the Geometry tab and the Size tab.

- **Views:** end view (shaft axis at the origin, seen from the free end) and side view (upper half section through the flat centres, axis horizontal from the cap's front face). Both are drawn at one shared scale (`side_by_side`, geometry_view.rs:~103), 3 mm apart (`VIEW_GAP_MM`), centred, on an `extreme_bg_color` plate with 4 pt corners.
- **Sizing:** the plate takes the full available width. Height is `drawing_height` (geometry_view.rs:221): what remains after the callout list, but at least 160 pt (`MIN_DRAWING_HEIGHT`) while the list keeps 3 rows (`MIN_LIST_ROWS`). The list scrolls. Below that floor the drawing shrinks to nothing and the list takes the height.
- **Parts and colours** (`part_color`, geometry_view.rs:77-87; `Part`, geometry.rs:63):
  - Body (hub, cup, web, boss): rgb(128,132,140).
  - Cavity (empty cup pocket): `extreme_bg_color` (20,22,28).
  - Magnet north: rgb(190,110,90).
  - Magnet south: rgb(95,125,175).
  - Retainer (316L sleeve and liner): rgb(150,175,165).
  - Cap (aluminium front cap): rgb(175,180,190).
  - Shaft: rgb(100,104,112).
  - Key: rgb(205,180,95).
- **Dimensions and callouts:**
  - A dimension is a 1.5 pt line with arrowheads and a numeric tag drawn on a background plate (12 pt font), coloured `DIMENSION` rgb(90,170,230).

## 6. State and persistence

- **Undo/redo** (`gui/history.rs`):
  - `MAX_UNDO_LEVELS = 100` (:16).
  - One step per settled edit, so a drag, a held arrow key, or a typed value in a text field is one step.
  - The `Design` snapshot covers inputs plus the sizing state.
  - View flags (welcome hidden, details toggle, card open or closed, tab, order, Minimum OD) are not in history.
- **Keyboard shortcuts** (`shortcuts`, panel.rs:872; consts panel.rs:114-123): Ctrl/Cmd+Z undo; Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y redo. They are ignored while a text field has focus, and a host can disable them (`set_keyboard_shortcuts`). Sliders take arrow-key nudges by their step. No other shortcuts.
- **Share link:** `?m=<deflate + URL-safe base64 of the design JSON>` (`session.rs:408-450`). It carries the inputs plus the sizing state (Auto mode and variable). The link is copied to the clipboard by **Copy share link**. The base is the page's own address (`set_share_base`), or `PUBLIC_BASE_URL` = `https://colesorkness.com/tools/magcoupler/` by default.
- **Design file:** format `magcoupling-design` v1 (`session.rs:56-61`), file `magcoupling-design.json`, maximum 1 MiB (`MAX_DESIGN_BYTES`, :83). Loading is one undo step. A refused file changes nothing and shows the reason in the header.
- **Exports:** the header's spreadsheet export and the results table's CSV, JSON and XLSX buttons. On the web they download through a Blob and a hidden `<a download>` (`app/files.rs:~30`).
- **Example design loading:** there is no separate loader. The defaults are the example design (`DesignInputs::default()`), restored by **Reset all** (which is undoable). The dashboard status says "Example design" while the inputs equal the defaults.
- **Local storage / persistence:** none. A grep finds no `localStorage`, no eframe persistence and no `App::save`. The URL is not updated. Everything is in memory for the session.
- **Logging for the smoke test:** console lines "magcoupling: loaded the design from the share link", "magcoupling sizing: ...", "magcoupling: loaded a design file", "magcoupling explorer: N equations".

## Appendix: the headless text-dump harness

A throwaway crate (`dump`, edition 2024, depends on `magcoupling-rs` with the `gui` feature and `egui = "0.32"`). It drives the real `MagcouplingPanel` without a window, clicks by label, and prints every painted text shape with its visibility. Usage: `dump <width> <height> [click:<label>|dump:<tag>]...`. Kept here so the overhaul plan can turn it into a first-paint word-budget test.

```rust
use magcoupling::gui::MagcouplingPanel;
fn flat<'a>(clip: egui::Rect, s: &'a egui::Shape, out: &mut Vec<(egui::Rect, &'a egui::Shape)>) {
    match s { egui::Shape::Vec(v) => v.iter().for_each(|x| flat(clip, x, out)), o => out.push((clip, o)) }
}
struct H { ctx: egui::Context, panel: MagcouplingPanel, w: f32, h: f32, last: egui::FullOutput }
impl H {
    fn frame(&mut self, events: Vec<egui::Event>) {
        let input = egui::RawInput { screen_rect: Some(egui::Rect::from_min_size(egui::Pos2::ZERO, egui::vec2(self.w, self.h))), events, ..Default::default() };
        let panel = &mut self.panel;
        self.last = self.ctx.run(input, |ctx| { egui::CentralPanel::default().show(ctx, |ui| panel.ui(ui)); });
    }
    fn settle(&mut self) { for _ in 0..5 { self.frame(vec![]); } }
    fn texts(&self) -> Vec<(egui::Rect, String, bool)> {
        let mut v = Vec::new();
        for c in &self.last.shapes { flat(c.clip_rect, &c.shape, &mut v); }
        v.into_iter().filter_map(|(clip, s)| if let egui::Shape::Text(t) = s { let r = t.galley.rect.translate(t.pos.to_vec2()); Some((r, t.galley.text().to_owned(), clip.intersects(r))) } else { None }).collect()
    }
    fn click(&mut self, label: &str) -> bool {
        let t = self.texts();
        let Some((r, _, _)) = t.iter().find(|(_, s, _)| s == label) else { println!("!! no text {label}"); return false };
        let p = r.center();
        let ev = |pressed| egui::Event::PointerButton { pos: p, button: egui::PointerButton::Primary, pressed, modifiers: Default::default() };
        self.frame(vec![egui::Event::PointerMoved(p)]);
        self.frame(vec![ev(true)]);
        self.frame(vec![ev(false)]);
        self.settle();
        true
    }
    fn dump(&self, tag: &str) {
        println!("=== {tag}");
        for (r, s, vis) in self.texts() { println!("{}\t{:.0}\t{:.0}\t{}", if vis {"V"} else {"H"}, r.min.x, r.min.y, s.replace('\n', " / ")); }
    }
}
fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let w: f32 = args[0].parse().unwrap(); let h: f32 = args[1].parse().unwrap();
    let ctx = egui::Context::default();
    ctx.set_theme(egui::ThemePreference::Dark);
    let mut hh = H { ctx, panel: MagcouplingPanel::new(), w, h, last: Default::default() };
    hh.settle();
    for a in &args[2..] {
        if let Some(l) = a.strip_prefix("click:") { hh.click(l); }
        else if let Some(t) = a.strip_prefix("dump:") { hh.dump(t); }
    }
}
```
